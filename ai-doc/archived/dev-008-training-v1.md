# DEV-008：教育訓練模式第一版

狀態：本地實作與核心 QC 完成；未部署。人類決策：課程歸檔、休息分段、背景處理、課程筆記模板；沿用一般／機密政策、匿名發言人與免費模型池。本輪在開發副本及獨立 DB 執行，不含正式切換、正式資料回填、push 或付費啟用。

- UX intent：錄製同仁建立一門課，分多次或多日加入段落；休息時保存本段，下一步是續錄，不等待 AI。課程頁清楚顯示各段保存／等待／失敗及筆記狀態。錄製頁保留課名與返回課程入口；保留既有收音及缺音軌阻擋。已保存不等於已上傳、已轉錄或筆記完成。
- 模式矩陣：一般會議沿用現有入口／欄位／AI 模板；教育訓練選課程／段落名稱／固定資料模式，以「休息並保存」與「繼續下一段」操作；機密課程僅本地轉錄與人工筆記模板。viewer 唯讀，editor 可建立／加入／排序／結課／重試，沿用既有分享範圍，不增加個人帳號或 ACL。
- ADR-TRAINING-001（本節為決策紀錄）：現有單檔會議無法表示同課多段及等待狀態。選擇新增獨立課程／段落／筆記快取資料表，段落引用既有持久化 jobs、可加入既有會議原文快照；不把整門課音訊合併為大檔，也不把課程稿塞入 D/R/A。代價為新增來源保護與備份引用；原會議 API／模板相容，既有列不遷移。本節取代先前僅討論的建議，其他 DEV 規格不變。
- 資料／狀態契約：課程 open→closed，可重新開課；段落以 client ID 冪等、固定 job ID，保存原始媒體與逐字稿。排序／加入／重新開課會提升 version 並使舊筆記可見過期；結課可先等待各段，全部轉錄完成後原子排入唯一筆記工作。失敗段保留來源與其他完成稿；筆記發布須核對 job／version，不能以舊工作覆蓋新課程。原文與時間不合併改寫、不假設跨段匿名代號相同。
- API 契約：`/training/courses` 清單／建立，課程詳情，預約段落、加入既有會議、順序、結課／重新開課；`/upload-media` 接受預約段落 ID 並在排入工作前綁定。所有寫入沿用 meeting:write，下載／播放採既有讀取權限與 Range。新增 SQL 採參數化、關鍵狀態採 transaction／版本檢查。
- 背景處理：沿用單一 worker 與模型額度等待／切換；教育段落完成逐字稿後停止，不逐段生成會議摘要。結課筆記依段落／有界文字批次快取，已完成稿不重新轉錄。模板為課程重點、概念名詞、操作步驟、案例、問答、講師交代作業與來源定位；無來源不補造，無作業不當待辦。機密模式不得自動轉雲端。
- 本機恢復：沿用 IndexedDB 保存每秒資料，增加課程／段落 client ID；「休息」需完成本機保存才釋放下一段操作，背景上傳以 session ID 處理，不能刪到新錄製。保存失敗保留記憶體檔及下載／重試入口；未送出片段不顯示課程完整。
- QA／QC：空課程、兩段休息續錄、慢上傳／AI 等待、重開頁面恢復、重複送出、同時結課、未完成／失敗段、只重試失敗段、加入既有課程稿、版本衝突、機密零雲端、viewer 禁寫、來源不可誤封存及備份指紋；既有全套回歸、架構／安全檢查。真實瀏覽器 1440×900／1024×768／390×844，主要 CTA 可見、無水平溢出、錯誤提示有下一步；UI 使用合成資料，不呼叫正式模型。
- FMEA：休息內容遺失 P0→保存完成門檻與恢復；錯課歸檔 P0→固定課名與穩定 ID；機密外送 P0→來源模式與工作發送前再檢查；缺段冒充完整 P1→等待／失敗可見；過期筆記覆寫 P1→version＋job fencing；長錄音重試浪費 P1→沿用分段 checkpoint；手機按鈕裁切 P1→實際 viewport 驗證。
- 停止條件：需要改正式資料、外送／成本／身份政策、覆蓋其他使用者變更或放寬主檔行數上限時先重新評估；本地必要修正持續執行。工程實作完成須有可重現測試與 UI 證據，不用單元測試冒充硬體收音或真實轉錄準確率。
- 後續 capsule（Future Phase Captured / Not Requested）：講義／投影片對照、測驗與學習追蹤；重新進入條件為使用者明確要求。保留課程／段落穩定 ID 與來源引用供後續使用，第一版不新增 LMS、日曆或真名聲紋。
- Release boundary：本輪僅本地開發驗證；正式 schema 及切換集中後續共用 release gate。本節不預寫部署或正式資料操作指令。
